# ElvUI_CombatAlert

**ElvUI_CombatAlert** is a small plugin for ElvUI that displays customizable combat in/out alerts on your screen.

Currently implemented features:
- Combat Begin / Combat End text alerts
- Fully movable frames via ElvUI movers
- Custom fonts, font sizes, outlines and colors
- Individual fade and display durations
- Optional sound effects per event
- Profile-safe configuration (ElvUI profiles supported)
- Localized configuration (multi-language ready)

This addon is designed to be lightweight.

> **Note:**  
> I am relatively new to Lua and World of Warcraft addon development.  
> This project is a learning experience, so the code may evolve and improve over time.

Feedback, suggestions and improvements are always welcome!
